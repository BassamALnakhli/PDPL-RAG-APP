# PDPL Legal RAG System
## About
This project is a Retrieval-Augmented Generation (RAG) system tailored specifically
for the Saudi Personal Data Protection Law (PDPL) and its executive regulations.
It functions as an AI legal assistant that streamlines complex regulatory research,
delivering accurate, source-cited answers strictly grounded in the official legal texts to ensure reliable and hallucination-free (_Hopefully_ :] ) guidance.
